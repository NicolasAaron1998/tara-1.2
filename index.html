Etiqueta img

La etiqueta "img" se utiliza para insertar una imagen en el texto.

Etiqueta input

La etiqueta "input" se utiliza para crear campos de entrada en formularios.

Etiqueta link

La etiqueta "link" se utiliza para vincular un archivo externo, como una hoja de estilo CSS.

Etiqueta meta

La etiqueta "meta" se utiliza para proporcionar metadatos sobre el documento HTML.

La parte de "charset" define la codificación de caracteres del documento.

La parte de "viewport" define el tamaño y la escala de la página en dispositivos móviles.

La parte de "description" te dice lo que se muestra en los resultados de búsqueda de Google.

Etiqueta Col

Sirve para definir propiedades y aplicar estilos en una o varias columnas de una tabla de forma conjunta.

Etiqueta embed

La etiqueta "embed" se utiliza para insertar contenido externo, como un video o un audio.

Etiqueta param

La etiqueta "param" se utiliza para definir parámetros para elementos como "object".
Esta obsoleta en los navegadores modernos y no se observara en los navegadores debido a que es un parametro interno

Etiqueta source

La etiqueta "source" se utiliza para especificar múltiples fuentes de medios para elementos como "audio" y "video".

Etiqueta wbr

La etiqueta "wbr" se utiliza para insertar un salto de línea en el texto, pero solo si es necesario.
